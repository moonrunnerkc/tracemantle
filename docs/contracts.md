# Input, dependency and report contracts

Sources are regular UTF-8 files, with an optional leading BOM. CRLF and CR are normalized for analysis; bundle hashing uses original bytes. The YAML opener and closer must be standalone `---` lines at column zero, optionally followed by horizontal whitespace. An opener without a closer is an error. Empty frontmatter parses as an empty mapping; required-field checks still apply. Multiline values are valid. Duplicate keys and non-string mapping keys, including YAML merge keys, are rejected. Bounded nonrecursive aliases are accepted and reported as portability advice. Recursive aliases are rejected. Source locations count from line one of the complete file.

Each read is limited to the selected cap plus one byte, including a file that grows during the read. SKILL.md is capped at 4 MiB, config at 1 MiB, legacy history at 8 MiB and imports at 5 MiB. YAML limits are depth 40, 20,000 nodes and 100 aliases; expanded alias structure has the same depth/node budget. JSON limits are depth 40 and 100,000 nodes, with duplicate keys and nonfinite numbers rejected. A skill batch is limited to 10,000 files and 128 MiB of source bytes. Resource closure is bounded to 32 levels, 10,000 resource paths/expanded Markdown files and 128 MiB. Immutable history reads are bounded to 10,000 records and 128 MiB total. Heuristic graphs are limited to 100,000 body lines and 10,000 nodes/headings. Expected encoding, resolution and filesystem errors become diagnostics; unrelated programming errors are not swallowed.

Directory symlinks are not traversed during discovery. Resolved duplicate source paths are validated once. Explicit source-file symlinks may resolve to regular files; dangling links, cycles and nonregular sources fail cleanly. A bundle manifest refuses symlinks and nonregular resources as incomplete identity rather than following them. Manifest names must be NFC-normalized, case-unambiguous relative paths with no controls, backslashes, drive prefixes or traversal segments. Files are sorted by normalized path; identity includes original bytes, full SHA-256, size and whether any executable bit is set. Only `.git`, `__pycache__`, `.DS_Store` and the legacy ledger are excluded. Evidence destinations must be outside evaluated bundles.

Markdown supports inline/image links (including angle-bracket destinations and titles), reference links/definitions, HTML href/src links, source/file/include directives and standalone path-like inline code. Fences use backticks or tildes, with matching delimiter length. Anchors and external schemes are not local files. A bare `report.json` inline-code mention is classified as a potential generated output; a path such as `scripts/helper.py` is a resource. Unsupported template/dynamic paths mark dependency coverage incomplete. Arbitrary programming-language imports, shell expansion and runtime-created dependencies are not inferred. A trusted check must explicitly declare its inputs and whether dependency coverage is complete; incomplete coverage requires full relevant-suite reruns on changes.

Standard API validation returns `ValidationResult`; its `valid` describes that file's errors, independent of strict policy. CLI validation JSON envelope schema 2 adds `tool`, `version`, `schema_version`, `gate` and `tokenizer` to the file summaries/results. Graph and prompt emit modes also emit one JSON object for single or multiple inputs. Single-graph fields and prompt fields are retained; multiple inputs appear under `results`. Historical ledger JSON keeps its v1 content fields. Product commands use envelope schema 1, with `command`, `exit_code` and `result`; manifest, check-evidence and imported history each have explicit content-schema versions.

Ignore prefixes are applied after merging symbolic, graph, model-judgment and history diagnostics. Final exit calculation runs after history diagnostics. Human output escapes untrusted C0/C1 controls; Markdown also escapes syntax delimiters. JSON preserves source values reversibly and uses JSON escaping. Quiet validation skips score explanations and report rendering. Prompt variants contain untrusted skill instructions as quoted task material, not instructions executed by TraceMantle.
